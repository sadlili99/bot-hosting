# 梨园托管台 · Bot 托管前端

iOS 26 液态玻璃风格的 Bot 托管台，**纯前端单文件**（`index.html`，零依赖、零构建），数据保存在浏览器本地，接后端时只换脚本里的 `API` 层。

## 功能

- 仪表盘：托管总数 / 运行中 / 今日消息 / 平均响应 / 异常重启，数字滚动更新
- Bot 卡片：状态、CPU / 内存实时条、运行时长走字、消息量、迷你趋势线
- 操作：开关启停、重启（带进度动效）、删除（二次确认）、点卡片看详情抽屉
- 添加 Bot：拖拽上传 .py，本机静态安全扫描（删文件 / 读凭证 / 外传 / 命令执行），有风险必须勾选确认
- 实时日志：全局日志流自动滚动，可暂停 / 清空；每个 Bot 有独立日志
- 主题：深色 / 白天 / 跟随系统 三档，顶栏按钮切换，玻璃材质与壁纸随主题变

## 放到 GitHub 上（GitHub Pages，免费）

1. 在 GitHub 新建一个**公开**仓库，例如 `bot-hosting`（不要勾选自动生成文件，保持空仓库）
2. 把本工程的 `index.html`、`.nojekyll` 上传到仓库根目录（或让小梨直接推送）
3. 仓库页 → Settings → Pages → Source 选 `Deploy from a branch`，分支选 `main`、目录选 `/ (root)`，保存
4. 等 1–2 分钟，页面上方会出现访问地址，形如：
   `https://<你的用户名>.github.io/bot-hosting/`
5. 以后改版：覆盖仓库里的 `index.html` 即可，Pages 会自动更新

> 注意：GitHub Pages 只能跑静态前端，跑不了 Python 后端。以后要接真后端（启停进程、真日志），把后端放 Render / 云服务器，前端 `API` 层改成请求那个地址即可，页面不用重写。

## 本地打开

直接双击 `index.html` 就能用；或在目录里跑 `python3 -m http.server 8080` 再打开 `http://localhost:8080`。
